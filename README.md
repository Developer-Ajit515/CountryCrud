# Country CRUD Application

A full-stack Country Management System developed using ASP.NET Core Web API and Angular 19.

## Features

- Add Country
- Update Country
- Delete Country
- View Country List
- Active / Inactive Status
- Responsive Bootstrap UI
- RESTful API Integration

## Technologies Used

### Backend
- ASP.NET Core Web API
- Entity Framework Core
- SQL Server
- C#

### Frontend
- Angular 19
- TypeScript
- Bootstrap 5
- HTML5
- SCSS

## Project Structure

CountryCrudAPI/

    Data/

CountryCrud/

## API Endpoints

GET    /api/Country

GET    /api/Country/{id}

POST   /api/Country

PUT    /api/Country/{id}

DELETE /api/Country/{id}

## Getting Started

### Backend

1. Open the API project in Visual Studio.
2. Update the SQL Server connection string.
3. Run the project.

### Frontend

```bash
npm install
ng serve
```

Open:

```
http://localhost:4200
```
